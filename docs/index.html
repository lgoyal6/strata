the point of all this

Storage engines earn trust by losing power at the worst possible byte. This button arms the same fault gate as tools/crash_test: a random kill offset a few hundred KB ahead, then writes until the gate tears one mid-write. Everything the engine acknowledged before the tear must survive the reboot. No exceptions.

The native build survives being SIGKILLed mid-write 11,149 times across 2.2M acknowledged writes with zero loss, and beats RocksDB 50x on synchronous commits through group commit (workloads where RocksDB wins are published too).
